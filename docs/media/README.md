# 发布素材占位目录

公开发布前，可以把经过脱敏的截图或 GIF 放在此目录，并在根目录 README 中引用。建议文件名：

- `node-overview.png`：节点默认状态和主要控件。
- `gallery-hover.gif`：悬停、下载和提示词角标交互。
- `prompt-details.png`：详情面板、复制按钮和来源链接。
- `pagination.gif`：加载、刷新和下一页的区别。

素材要求：

- 删除 API Key、Cookie、用户目录、内部服务器地址和私人图片。
- 图片来源必须允许展示；截图中的 Civitai 内容应保留来源标记。
- GIF 尽量控制在 10 MB 以内，截图使用 PNG/WebP。

当前仓库不附带真实截图，避免把个人环境信息或未经确认的第三方图片提交到公开仓库。
